To je repozitorij za končni projekt pri predmetu Interaktivnost in oblikovanje informacij.

Navodila:
- zaženemo python skripto KoncniProjekt.py z ukazom py KoncniProjekt.py
- Če na sliki kamere ni rok, potem ribe same plavajo po ekrano.
- Če je na sliki ena roka potem ji sledijo
- Če je na sliki več rok se ribe razporedijo med roke
- Če hitro pomahamo z roko, potem se ribe za 5 sekund oddaljujejo od roke
